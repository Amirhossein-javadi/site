# سامانه فروش و انبار — Frontend (React + Vite)

رابط کاربری فارسی/RTL متصل به بک‌اند جنگو.

## اجرا

```powershell
npm install
copy .env.example .env      # لینوکس/مک: cp .env.example .env
npm run dev
```

روی `http://localhost:5173` باز می‌شود. **بک‌اند باید هم‌زمان روی
`http://localhost:8000` در حال اجرا باشد.**

## صفحات

| مسیر | وضعیت |
|---|---|
| `/dashboard` داشبورد | متصل — آمار واقعی از API |
| `/products` محصولات | متصل — کاتالوگ با قیمت و موجودی |
| `/inventory` موجودی و سریال | متصل — موجودی، سریال‌ها و ثبت ورود کالا |
| `/contracts` قراردادها | متصل |
| `/orders` سفارش‌ها | متصل — ایجاد سفارش، رزرو موجودی و گردش وضعیت |
| `/proforma-invoices` پیش‌فاکتورها | متصل — صدور و مشاهده Snapshot قیمت |
| `/payments` پرداخت‌ها | متصل — پیگیری پرداخت Mock و ثبت نتیجه |
| `/credits` اعتبارات | متصل — مانده و دفتر مالی هر قرارداد |
| `/reports` گزارش مالی | متصل — فیلتر گردش‌ها بر اساس قرارداد و تاریخ، خروجی CSV سازگار با Excel |
| `/suppliers` تأمین‌کنندگان | متصل — ثبت، ویرایش و مدیریت وضعیت |
| `/customers` مشتریان | متصل — مدیریت شرکت‌های نماینده |
| `/shipments` ارسال‌ها | متصل — اطلاعات رهگیری و ثبت تحویل |
| `/returns` مرجوعی‌ها | متصل — درخواست، تأیید/رد و دریافت انبار |

## ساختار

- `src/layout/` — Sidebar، Topbar، Layout
- `src/pages/` — یک فایل به ازای هر صفحه
- `src/components/ui.jsx` — Card، Badge، DataTable، Skeleton، EmptyState و…
- `src/lib/api.js` — کلاینت متمرکز API؛ آدرس از `VITE_API_BASE_URL`
- `src/lib/hooks.js` — هوک `useApi` و توابع قالب‌بندی عدد/مبلغ/تاریخ

## نکته

منطق کسب‌وکار (محاسبه موجودی قابل فروش، اعتبارسنجی رزرو، قیمت و دریافت
مرجوعی) در بک‌اند است. درگاه پرداخت فعلی Mock است و پول واقعی جابه‌جا نمی‌کند.
